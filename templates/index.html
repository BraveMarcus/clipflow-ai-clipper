GOOD TO KNOW

Frequently asked questions

Are captions automatic?

Yes. When enabled, speech is transcribed and subtitles are burned into the clip. Review them for transcription errors.

Which formats can I choose?

Vertical 9:16 for Shorts/Reels, square 1:1 for feed posts, and horizontal 16:9 for standard YouTube videos.

Is every YouTube link supported?

No. Private, age-restricted, live, region-restricted or otherwise unavailable videos may fail. Free hosting can also impose processing limits.

Is it completely free to run?

The code is free, but hosting and processing resources can have limits or costs. GitHub Pages alone cannot run the Python video-processing backend.
